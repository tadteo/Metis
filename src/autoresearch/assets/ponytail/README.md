# Ponytail attribution

Coding efficiency instructions adapt DietrichGebert/ponytail (MIT), revision
`e3ba2aa6f1e6f0bc4d69eb09c9f0d0a93af56156`. The original [skill](https://github.com/DietrichGebert/ponytail/blob/e3ba2aa6f1e6f0bc4d69eb09c9f0d0a93af56156/skills/ponytail/SKILL.md)
and license are preserved here; upstream-skill.md is inert, never loaded into agents.
The active adaptation is specs/prompts/coding_efficiency.md.

Metis retains reuse-first implementation and avoiding speculative complexity.
It omits intensity modes, one-line preferences, restricted test coverage, reduced
requirements and output-format rules. Scientific fidelity, evidence preservation,
meaningful tests and the typed coding protocol take precedence. No lifecycle hooks
or globally installed plugin are needed. This is a local adaptation, not an exact
upstream invocation or a claim of upstream benchmark performance.

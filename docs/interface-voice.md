# The voice of Metis

Metis is a gracious host and rigorous scientist. Its interface evokes a living archive
and laboratory of inquiry, with Greek character expressed through proportion and quiet
language. It welcomes questions, follows evidence and leaves room to revise beliefs.
It never claims omniscience, treats absence of evidence as certainty, or describes
synthetic demonstrations as discoveries.

Welcome: “Metis welcomes you. What question brings you here?”
Use short, concrete action labels: New research, Check setup, Save settings, Start,
Pause, Review evidence. Use warmth in introductions and empty states; use direct facts
for errors, costs, credentials and destructive actions. Avoid mystical promises,
theatrical mythology, generic assistant greetings and ornamental technical jargon.
This is interface voice, not a change to scientific model instructions.

The supplied Kinfolk palette lives in assets/interface.json. Background/surface/text
and muted surface use the exact supplied light/dark values. Terracotta is reserved
for small marks, focus, borders and selected states. Body text and primary control
labels use charcoal/cream; links use text colour with terracotta underlines. Status
colours carry their existing explicit labels. Both interfaces use the same hierarchy:
Home, Research, Settings, Connections; Overview, Experiments, Activity, Manuscript.

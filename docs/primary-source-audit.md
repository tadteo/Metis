# Primary-source repair audit

Reviewed 2026-09-29. This file records release boundaries; the executable component matrix is [fidelity.json](fidelity.json).

The source of truth is [ScientistTwo v1](https://arxiv.org/html/2609.19644v1), especially sections 3.1–3.6, section 4.2 and Appendix A.2. Table 5 reports zero, one and two rebuttal-enabled cycles; this implementation preserves `peer_rounds` as total assessments including initial. Default two allows one experimental revision; setting three permits two cycles and has a regression fixture. Appendix A.2 uses ambiguous round/refinement wording, so this is an explicit interpretation, not a claim to have recovered private orchestration. The published stage vocabulary is retained in `stage_decision`; legacy decisions remain readable for saved runs. The seed-pool count and initial N0 are symbolic in the body, so eight and two remain explicit reconstruction settings rather than recovered constants. The paper's two-reference novelty search is retained as an evaluation variant; the requested broader retrieval is the normal configuration and never claims exhaustive coverage.

The [official project](https://scientist-two.github.io/) and [official GitHub account](https://github.com/scientist-two) were checked again. The account exposes its website, papers and supporting results, but no executable orchestration release or ScientistTwo role-prompt pack. Only that exact artifact is marked unavailable. The stage behavior is reconstructed and implemented rather than deferred.

[ScientistOne / Chain-of-Evidence](https://arxiv.org/html/2605.26340v1#S5) defines score reruns, specification violation, reference verification and method–code alignment. The repaired implementation adds claim extraction with deterministic metric verification, independent coverage/entailment checks, iterative source inspection, clean reruns of selected supplementary results, failed-attempt denominators and immutable artifacts. These checks have meaningful regression tests but their false-negative rate is not calibrated against the published CoE benchmark.

The PaperOrchestra, PaperBanana and ScholarPeer source/code/prompt audits are in [PaperOrchestra integration](paper-orchestra.md) and [ScholarPeer reconstruction](scholarpeer.md). Official released agents and templates are used where available. ScholarPeer's exact Appendix G assets are attributed with their source and hashes. Its unavailable few-shot content is explicitly identified rather than substituted silently.

The [Stanford Agentic Reviewer service](https://paperreview.ai/) is a held-out evaluator in ScientistTwo. A generic independent model panel is not that service. This implementation supports a frozen final manuscript evaluation through a separately configured provider or operator command adapter, and stores its output outside all optimization feedback. No acceptance-probability interpretation is applied to simulated review scores.

The [xAI model documentation](https://docs.x.ai/developers/models/grok-4.7) confirms Grok 4.7 as the current public API model at inspection. [Laya's official implementation](https://github.com/NandhaKishorM/laya) exposes `/v1/systemone` typed decisions and does not generate prose or code. Laya therefore has a real configurable transport for bounded advisory triage, while scientific adjudication and generative work retain capable reasoning models. Context overflow, request failure, invalid structured output, critic disagreement and coding repair failures trigger explicit escalation or unresolved outcomes; cheaper calls do not authorize weakened acceptance conditions.

Credential availability is not evidence of a completed experiment. Live model capability, writer quality and calibrated reviewer agreement remain unmeasured. Actual retrieval smoke tests and public dataset baseline executions are recorded separately from deterministic integration tests. A passing architectural suite is not parity evidence.

The retained [live literature smoke](evidence/literature-live-smoke.json) was inherited from the frozen concurrent snapshot, including the original Semantic Scholar rate limit and Crossref decoding failure and the later successful Crossref recheck. This documentation task did not rerun those requests. The [public baseline report](../evaluations/baseline-results.json) records executed digits/diabetes baselines; the superseded report remains separately archived after the full-data diabetes scaling defect was corrected. Neither report contains an autonomous scientific capability score.

Scientific safeguards added locally include exact numeric spans (including LaTeX percentages), explicit relative versus percentage-point units, registered protected-evaluator outputs, original-input reproduction, supported paired sign-flip arithmetic and Bonferroni correction. These enforce evidence provenance and supported arithmetic; they cannot decide whether a study design or significance claim is scientifically appropriate.

# Metis documentation

Start with the [README](../README.md) for installation and a short tour. Metis is an
experimental research platform; the [fidelity report](fidelity.md) distinguishes
implemented behavior from measured scientific capability.

## Use Metis

- [User guide](usage.md): create, run, inspect and resume research.
- [Execution options](execution-options.md): Docker, local and cluster execution.
- [Remote connections](remote.md): connect to a controller on another host.
- [Model routing](model-routing.md): configure providers and roles.
- [Security and privacy](../SECURITY.md): trust boundaries and private state.

## Understand the system

- [Architecture](architecture.md) and [AI system](ai-system.md): modules, agents and workflow.
- [Reproducibility](reproducibility.md) and [accounting](accounting.md): recorded runs,
  artifacts and cost limits.
- [Paper specification](paper-spec.md), [fidelity report](fidelity.md) and
  [capability evaluation](evaluation.md): scientific contracts and evidence limits.

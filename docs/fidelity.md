# ScientistTwo fidelity matrix

Canonical machine-readable data: [fidelity.json](fidelity.json). Each row is schema-checked and linked to source evidence and executable checks. Software tests do not establish scientific parity.

Paper fidelity, engineering extensions, intentional model substitutions and measured capability are separate `category` fields. Status describes the implemented behavior, not performance validation. Only unavailable original prompts are marked missing after a primary-source release audit.

The implementation now runs pinned official PaperOrchestra agents and uses released ScholarPeer Appendix G prompts. Live scientific capability remains unmeasured until model credentials and external evaluation are available.
